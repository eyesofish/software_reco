# Workflow: FastAPI 推荐请求处理

## Trigger
- API: `POST /api/v1/recommend`

## Steps
1. 接收请求并执行参数校验。
2. 创建带路由的推荐 Agent。
3. 使用请求参数初始化一次执行的 `AgentState`。
4. 异步执行 Agent 工作流并获得结果。
5. 提取结果中的核心字段并组装统一响应。
6. 返回推荐结果。

## Key State / Artifact
- `RecommendationRequest`（`query`、`timeout`、`max_iterations`）
- `AgentState`（`user_query`、`timeout_budget`、`max_iterations`、`start_time`）
- `RecommendationResponse`（`status`、`final_answer`、`candidates`、`mode`、`iteration_count`、`coverage`）

## Termination
- 正常结束条件：返回推荐响应（`status=success`）。
- 异常/失败分支：请求校验失败返回 422；执行异常返回 500。

# Workflow: Agent 路由执行流程（RAG / Chat / Draw）

## Trigger
- 事件：`create_rag_with_routing_agent()` 创建的工作流被 `ainvoke` 调用（来源包括 API、CLI、服务层调用）。

## Steps
1. 进入入口节点，记录会话消息并初始化执行时间。
2. 对用户查询进行规范化。
3. 进行模式路由，选择 `rag`、`chat` 或 `draw` 分支。
4. 若进入 `rag` 分支：生成子问题，收集证据，评估证据，生成候选方案，执行覆盖率检查。
5. 在 `rag` 分支中按条件循环：满足继续条件时回到证据收集，不满足时进入答案生成。
6. 若进入 `chat` 分支：直接生成聊天回答后结束。
7. 若进入 `draw` 分支：先生成绘图参数，再执行绘图后结束。

## Key State / Artifact
- `AgentState.mode`
- `AgentState.normalized_query`、`constraints`、`sub_questions`
- `AgentState.evidence`、`candidates`
- `AgentState.coverage`、`needs_refinement`、`iteration_count`
- `AgentState.final_answer`、`drawing_params`、`image_result`、`messages`

## Termination
- 正常结束条件：`rag` 分支在满足终止条件后生成最终答案并结束；`chat` 分支完成回答即结束；`draw` 分支完成图像生成即结束。
- 异常/失败分支：节点执行异常向上抛出，由调用方流程处理失败结果。

# Workflow: 向量库初始化流程

## Trigger
- API: `POST /api/v1/initialize-db`
- CLI: 启动 `run_agent.py` 时传入 `--init-db`

## Steps
1. 构建初始化文档集合（示例软件资料与元数据）。
2. 调用向量库初始化入口。
3. 写入目标向量集合并完成初始化。
4. 返回初始化结果。

## Key State / Artifact
- 初始化文档列表（`content` + `metadata`）
- 向量集合：`software_recommendations`
- 返回状态：成功/失败标记与消息

## Termination
- 正常结束条件：初始化成功并返回成功状态。
- 异常/失败分支：初始化失败时返回失败结果；API 分支返回 500。

# Workflow: CLI 推荐会话流程

## Trigger
- 事件：执行 `software_recommend_system/run_agent.py`

## Steps
1. 解析命令行参数并设置运行模式。
2. 按参数决定是否先执行向量库初始化。
3. 创建带路由的推荐 Agent。
4. 单次模式：读取 `--query`，创建 `AgentState`，执行一次 Agent。
5. 交互模式：循环读取用户输入，更新状态并反复执行 Agent。
6. 输出每次执行结果。

## Key State / Artifact
- CLI 参数（`query`、`timeout`、`max_iterations`、`init_db`、`debug`）
- 会话中的 `AgentState`（交互模式下跨轮更新）
- 每轮输出的推荐结果字段

## Termination
- 正常结束条件：单次模式完成一次执行；交互模式收到 `quit/exit` 后退出。
- 异常/失败分支：`KeyboardInterrupt` 或运行异常导致当前流程中断/退出。
