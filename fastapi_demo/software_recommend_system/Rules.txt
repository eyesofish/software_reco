# Rules

## Code Style
- 对外接口契约（FastAPI 请求/响应）与核心状态/文档结构必须使用 Pydantic 模型定义（`BaseModel`/`Field`），不得以裸 `dict` 作为契约。
- 配置项必须集中在 `Settings` 类中通过环境变量读取（`load_dotenv()` + `os.getenv(...)`），禁止在业务逻辑中硬编码可配置值。
- 需要记录运行信息时，统一使用模块级 logger（`logging.getLogger(__name__)`）。

## Architecture
- `app/` 仅负责 FastAPI Web 层（应用装配、路由、启动钩子）；`software_recommend_system/` 负责推荐 Agent、检索、工具与工作流实现。
- 所有 v1 接口必须挂载在 `"/api/v1"` 前缀下。
- 推荐执行链路必须通过 `create_rag_with_routing_agent()` 创建的 LangGraph 工作流运行，并以 `AgentState` 作为状态载体。
- 向量数据读写统一使用 Chroma 持久化存储，集合名固定为 `"software_recommendations"`。

## API & Data Contract
- `POST /api/v1/recommend` 请求体字段固定为：`query`（长度 `1..1000`）、`timeout`（`10..300` 秒）、`max_iterations`（`1..10`）。
- `POST /api/v1/recommend` 成功响应必须包含：`status`、`final_answer`、`candidates`、`mode`、`iteration_count`、`coverage`。
- 调用 Agent 时必须提供 `AgentState.user_query`、`AgentState.timeout_budget`、`AgentState.max_iterations`、`AgentState.start_time`。
- 文档数据契约必须满足：`Document.content`、`Document.metadata`、`Document.score` 必填，且 `metadata.source` 必填。

## Error & Test
- 请求参数校验错误统一返回 HTTP 422，响应体格式固定为 `{"detail": exc.errors()}`。
- 路由中的运行时异常统一转换为 HTTP 500（`HTTPException`），并在 `detail` 字段返回错误信息。
- `similarity_search` 在向量集合不存在时必须返回空列表；仅非该场景的异常继续抛出。
- `initialize_vector_store` 发生异常时必须记录错误并返回 `False`。
